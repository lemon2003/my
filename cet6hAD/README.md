# 六级高频词汇（cet6hAD）

单词卡片学习页，一套首页共三个词库：

- **优路六级**：来自《优路教育 · 六级英语 · 高频词汇》PDF，16 个 Word List / 1200 词，带音标、搭配、记忆。
- **百词斩**：来自 [lemon2003/cet6hAD](https://github.com/lemon2003/cet6hAD) 的 `words1..29.js`，29 组 / 2902 词，按原样收录（只有单词 + 词义，没有音标与搭配）。
- **六级全部单词**：来自 `大学英语六级词汇完整带音标-可打印-可编辑-乱序版.xls`，74 个单元 / 5518 词，自带音标与释义。

纯静态站点，无构建依赖、无后端，起个静态服务打开 `index.html` 即可运行。

### 桌面版（不用浏览器）

已用 Electron 打包成独立桌面程序，双击出独立窗口，没有地址栏、标签页和菜单栏：

```
优路六级\desktop\cet6-vocab-win32-x64\六级高频词汇.exe
```

（打包工程在同级的 `优路六级\desktop-build\`，`node build.js` 可重新打包，`node repack.js` 只重建 asar。）

- 全套站点已经打进 `resources\app.asar`（约 2.5 MB），程序目录可以整个拷走，换台电脑也能直接跑。
- 快捷键：`F11` 全屏切换、`Esc` 退出全屏、`Ctrl+0` 恢复 100% 缩放；其余按键与网页版完全一致（`→` / `空格` / `Enter` 下一个，`←` 返回首页）。
- 窗口大小和位置会被记住；重复双击只会聚焦已经打开的窗口，不会开出第二个。
- 背诵进度存在 `C:\Users\<用户名>\AppData\Roaming\六级高频词汇\` 下，**与浏览器里那份互不相通**。如果已经在网页版背过一部分，桌面版会从零开始。
- 建桌面快捷方式：右键 `六级高频词汇.exe` → 发送到 → 桌面快捷方式。

### 单元怎么划分

**按 PDF 里原生的 `Word List 1 / 2 / 3 …` 分节，不是按每 100 词硬切。**

- 每个 Word List 在原件里都有蓝色横线夹着的「Word List N」标题；标题可能在页顶，也可能在某一栏中间，所以同一页的词可能分属两节（第 4 页：`organization` 之前属 Word List 2，之后属 Word List 3）。
- 每节 75 词是数据完整性的自检口径：少录一整栏、或多切一段，词数就会偏离 75。
- 百词斩沿用原仓库的 29 组，不做重新切分；六级全部单词没有原书分节，按表内顺序每 75 词切一个单元。

### 数据形态

三份词库都已转录、切分、生成完毕，直接以 `wordsN.js` / `extraN.js` / `allN.js` 的形式随页面存放，**打开即用，没有任何预处理步骤、没有构建依赖**。

源表与导入脚本不在本目录内。`words.txt`（优路词表）、`大学英语六级词汇…乱序版.xls`（全部单词源表）、`_repo_src/`（百词斩原仓库）以及 `tools/` 下的导入器与构建器，都属于「只在重建词库时才用」的文件，已在清理时移除。

需要增删词条时**不要直接手改 `wordsN.js` / `extraN.js` / `allN.js`**：它们是生成物，三列数据（单词 / 音标 / 释义）与 `manifest.js` 里的词数必须同步。正确做法是取回源表与导入脚本，重跑一遍生成流程。

## 玩法

- 进入任一单元，单词卡片随机散落在页面中，卡片上是**单词 + 音标**（大字号，投影/近视也看得清）。
- 卡片永远不会互相重叠：先随机找位置，随机失败就按 6px 网格逐点扫描；真的排满了就淘汰最旧的卡片腾地方（标记卡片最后才让位）。底部按钮和右上角计数是保留区，卡片不会压在上面。
- 点卡片弹出详情：**音标 / 按词性分行的词义 / 搭配（逐条）/ 记忆**；没有的分区自动隐藏。
- 弹窗内可「标记」该词，标记后卡片变荧光黄并常驻。
- **同屏硬上限 20 张，标记卡片同样占位。** 新词进来时从「消失队列」队首开始找：已标记的跳过，删掉第一张未标记的，新词补进去（即「1 号被标记就删 2 号」）。队列顺序就是卡片出现的先后顺序，与摆放位置无关。
- 20 张全部被标记时不再放新词、「单词 x/75」计数停住，并弹框提示：目前屏幕上单词数量为20，请先背完当前20个单词后，再背新单词吧。关掉提示后点卡片取消标记即可继续。
- 取消标记 = 这个词已经背会、可以让位：卡片**移到消失队列队尾**，要等前面 19 张都淘汰完才轮到它。注意边界：若屏幕上其余 19 张都还是标记状态，它就是唯一未标记的一张，下一次出现新词时会被立即替换。
- 「下一个」或键盘 `→` / `空格` / `Enter` 继续，`←` 返回首页，`Esc` 关闭弹窗，弹窗内按 `M` 快速标记。
- 页面正中有一行灰色水印，写着当前单元（优路是 `Word List N`，原仓库是 `第 N 组`）。水印在卡片层下面（`z-index: 0`，卡片是 `5`），并设了 `pointer-events: none`，所以既不挡卡片也不挡点击。

## 背诵进度（已背过 / 一键重置）

- 判定口径：**一个 Word List 里的每个词都被翻到过一次**，这一节就算「已背过」。
- 首页按钮转成浅绿色并显示 `✓ 已背过 · 可重背`；按钮仍是普通链接，点进去可以重新背。
- 只翻了一部分的显示 `已看 30/75`，不转绿。
- 首页分三块：**优路六级**（Word List 1–16）、**百词斩**（第 1–29 组）、**六级全部单词**（第 1–74 单元），同一套玩法、同一套进度，进度按单元 id 前缀分开存。
- 每个栏目标题旁标注规模（`共 16 单元 · 1200 词`），右上角各有一个「一键重置」，**只清本栏目的记录**；栏目之间互不影响。
- 记录存在 localStorage 的 `cet6hAD.progress.v3` 键里，按单元存「看到过的词下标」，补词或重排不会造成虚高；浏览器禁用存储时只是不记忆，不影响学习。

## 配色（糖果撞色）

全站配色集中在 `words/theme.css`，页面里不写死任何颜色。四种状态四种色相，不允许混用：

| 状态 | 配色 | 出现位置 |
|---|---|---|
| 当前正在看的词 | 蓝底白字 `#2563EB` | 学习页卡片、主要按钮 |
| 已标记的词 | 荧光黄底 + 黑描边 `#FFD400` | 学习页卡片、弹窗「标记」按钮 |
| 还没看的词 | 白底 + 2px 黑描边 | 学习页卡片 |
| 已背过的单元 | 浅绿底 + 绿字 `#DFF5E6 / #2F7D52` | 首页单元按钮 |
| 页面底色 | 奶油黄 `#FFF7E6` | 全站 |
| 单元水印 | 半透明灰 `rgba(74,66,52,0.13)` | 学习页背景层（卡片之下） |

首页单元按钮左侧还有一条 6px 色条，按蓝 / 黄 / 粉 / 绿 / 紫循环，用来区分相邻单元。
换配色：只改 `theme.css` 里的变量值即可，`index.html` 与 119 个单元页会自动跟着变。

## 目录结构

```
index.html                首页：三个栏目列表 + 各自进度与重置（无搜索框）
ico.ico                   标签页图标
words/
  manifest.js             优路六级各节 id 与词数（首页用）
  progress.js             背诵进度读写（localStorage，支持按栏目清除）
  wordLearner.js          卡片学习器（卡片放置、翻页、弹层渲染、键盘快捷键）
  theme.css               配色变量（唯一定义处，改配色只动这个文件）
  style.css               学习页样式
  wordsN.html / wordsN.js 各 Word List 页面外壳与词库数据
extra/                    百词斩词表（复用 words/ 的 style.css / progress.js / wordLearner.js）
  manifest.js             29 组的 id 与词数，首页用
  extraN.html / extraN.js 第 N 组页面外壳与词库数据
all/                      六级全部单词（同样复用 words/ 的样式与脚本）
  manifest.js             74 个单元的 id 与词数，首页用
  allN.html / allN.js     第 N 单元页面外壳与词库数据
```

项目根目录（`优路六级/`）里除 `cet6hAD/` 外，还有三项与桌面版相关的：

```
优路六级-构建源备份-*.zip   词表源文件与生成脚本的备份（改词时从这里解出来重跑）
desktop/                  打包产物：cet6-vocab-win32-x64\六级高频词汇.exe（约 354 MB）
desktop-build/            打包工程：main.js + build.js + repack.js + package.json（约 53 KB）
```

`desktop-build/` 里**没有 `node_modules`**（380+ MB 的 Electron 依赖已删）。exe 自包含，删了不影响运行；只有需要重新打包时才要先装一次依赖：

```bash
cd desktop-build
npm install --registry=https://registry.npmmirror.com
# npm 会静默跳过 Electron 二进制下载，要手动补一次（否则 dist/ 为空，打包报错）
ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ node node_modules/electron/install.js
node build.js
```

合计 `1` 个首页 + `16 + 29 + 74 = 119` 个单元页，共 `1200 + 2902 + 5518 = 9620` 个词。除 `progress.js` / `wordLearner.js` / 两份 CSS 与 `index.html` 外，其余 js 与全部 html 均由脚本生成。

## 已知限制

- 「标记」只在内存里，刷新即重置；「已背过」是持久的。
- 302 条没有搭配，是原书这些词只有释义（或释义 + 记忆），不是漏录。
- 百词斩那 2902 条没有音标、搭配、记忆，卡片只显示单词，弹层只显示释义；这是源数据就没有，未做机器补全。
- 六级全部单词第 74 单元只有 43 词（5518 不能被 75 整除），其余 73 个单元都是满 75 词。
- 词库源自扫描件转录与第三方词表，建议偶尔抽查比对原件；音标沿用了书上的英式写法（如 `/ˈɑːsk/`），未做美式对齐。
